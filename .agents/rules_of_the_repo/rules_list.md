| Skill | When it applies | Rule type | Configuration |
|---|---|---|---|

| [context_md_system](../skills/context_md_system/SKILL.md) | File changes, source folders, exported interfaces, CONTEXT.md maintenance | Living rule without human approval | none |
| [docs_folder_system](../skills/docs_folder_system/SKILL.md) | Any change inside docs/ | Static rule | [config.md](config/docs_folder_system/config.md) |
| [jerome-rust-style](../skills/jerome-rust-style/SKILL.md) | Creating or editing Rust source files | Static rule | none |
| [jerome-typescript-javascript-style](../skills/jerome-typescript-javascript-style/SKILL.md) | Creating or editing TypeScript or JavaScript source files | Static rule | none |
